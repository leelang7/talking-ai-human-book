## 무엇을 보아야 하나

**눈이 깜빡입니다.** 신경망이 아니라 코드가 만듭니다. 2~5초 난수 주기, 0.3초 사인 반파장(Ch19 §2).

**말할 때 입이 움직입니다.** 음소 분석이 아니라 **오디오 음량** 이 엽니다(Ch17).

**언어모델을 한 번도 부르지 않습니다.** 입력창의 대본이 그대로 목소리가 됩니다. 머리 층은 Ch07 에서 붙입니다.

---

## 코드에 심어 둔 것 — 나중에 배울 것들의 씨앗

| 코드 | 나중에 | 왜 지금부터 |
|---|---|---|
| 첫 클릭에서 `AudioContext` 깨우기 | Ch17 §3 | 없으면 **첫 메시지만 입이 안 움직임**(실패 20번) |
| `Math.max(0.06, …)` 눈 하한 | Ch16 §4 | 0까지 감으면 눈이 **사라짐**(실패 25번) |
| `speaking` 일 때 입 최소 진폭 | Ch17 §4 | 분석이 조용히 실패해도 입은 움직임 |
| `scaleY` 늘리며 `scaleX` 좁히기 | Ch16 §4 | 세로만 늘리면 입이 **네모나게** 커짐 |
| `onended` 에서 입 닫기 | Ch17 §6 | 반쯤 벌어진 채 굳는 것 방지(실패 24번) |
| 이모지·특수문자 제거 | Ch03 §4 | TTS 가 읽어버리거나 침묵함 |

**60줄 남짓한 스크립트에 실패 카탈로그 다섯 개의 예방책이 이미 들어 있습니다.** 부록 F 를 먼저 읽고 오면 이 코드가 다르게 보입니다.

## 검증 기록 (2026-08-05)

| 항목 | 결과 |
|---|---|
| `GET /` | HTTP 200 · 4,077 bytes |
| `POST /say` (ASCII) | `{"url":"/audio/v1.mp3"}` |
| `POST /say` (한글) | `{"url":"/audio/v2.mp3","text":"테스트"}` |
| 생성 오디오 | **MPEG layer III · 24kHz · 모노** |

> **테스트 중 만난 함정** — Git Bash 에서 `curl -d '{"text":"한글"}'` 이 실패합니다. 셸이 인자의 한글을 깨뜨리기 때문이고 **코드 문제가 아닙니다.** 파일로 넘기면(`--data-binary @body.json`) 통과합니다. 부록 H 의 Windows 인코딩 문제와 같은 뿌리입니다.
