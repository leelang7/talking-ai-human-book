## 채점 기준 (항목별 0 · 절반 · 만점)

**동작** — 0: 결과물 없음 / 절반: 나오지만 재현 명령이 없다 / 만점: 남이 그 명령으로 같은 것을 만든다.
**검증** — 0: "눈으로 보니 괜찮았다" / 절반: 적중률만 / 만점: 기준선과 조용한 구간까지, 그리고 **지표가 무엇을 못 잡는지** 한 줄.
**선택의 근거** — 0: "제일 유명해서" / 절반: 트랙은 맞는데 파라미터 근거가 없다 / 만점: 같은 값이 다른 조합에서 왜 실패하는지 안다(Ch12 §6).
**실패 기록** — 0: 없음 / 절반: 실패 목록 / 만점: **실패를 분해한 기록** — 여러 선택을 한꺼번에 바꿨다가 전부 버린 것을 스스로 짚는다.
**책임** — 0: 없음 / 절반: 동의서만 / 만점: 철회하면 무엇이 지워지는지 로그로 답할 수 있다.

## 왜 실패 기록에 점수를 주는가

점수에 넣지 않으면 학생은 실패를 숨깁니다. 넣으면 기록합니다. **그 기록이 다음 기수의 교재가 됩니다** — 부록 F 가 그렇게 만들어졌고, 이 책의 Ch13 §4 도 저자의 실패 폴더에서 나왔습니다.

## 감점이 아니라 0 점인 것

- 동의 없는 얼굴·음성을 쓴 결과물 → 항목 5 가 0 이 아니라 **프로젝트 전체 0**. Ch29 §3 의 기준선은 협상 대상이 아닙니다.
