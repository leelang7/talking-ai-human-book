## 1. 도서소개 (붙여 넣기)

```
사진 한 장이 말하기까지 4분, 브라우저 아바타가 대답하기까지 2초. 같은 얼굴을 두 개의 시간으로 만드는 법을 다룹니다.

AI 휴먼은 하나의 거대 모델이 아닙니다. 얼굴, 목소리, 두뇌, 기억 네 층의 조립입니다. 이 책은 그 네 층을 소비자 GPU 한 장(RTX 4070 SUPER 12GB)에서 직접 조립하고, 각 단계가 몇 초 걸리는지 전부 재서 적었습니다.

세 갈래로 나뉩니다. Track A는 사진 한 장으로 만드는 추모 영상입니다. 립싱크와 리타게팅을 층으로 나누고, 사람이 아닌 얼굴(반려동물, 캐릭터)까지 말하게 합니다. Track B는 GPU 없이 브라우저에서 도는 실시간 대화 아바타입니다. 2D 파츠와 3D VRM, 음량 립싱크, 감정 태그와 제스처로 2초 안에 대답하게 만듭니다. Track C는 인격입니다. 페르소나, 끼어들기, 실시간 통역, 기억 3층, RAG, 여러 아바타, 그리고 평가 하네스까지 갑니다.

이 책의 특징은 셋입니다.

첫째, 모든 숫자가 재현됩니다. 본문의 수치는 공개 저장소의 스크립트가 낸 값이고 결과 파일이 그대로 들어 있습니다. 어떤 스크립트가 어떤 숫자를 냈는지는 부록 C에 표로 있습니다.

둘째, 실패를 숨기지 않습니다. 부록 F는 실패 카탈로그 50종입니다. 증상, 원인, 대안 순서로 적었고 폐기한 경로도 사유와 함께 남겼습니다.

셋째, 만들지 않을 것도 다룹니다. 동의와 표시, 거절 기준을 절차와 서식으로 옮겼습니다. 2026년의 표시 의무는 권고가 아니라 법입니다.

파이썬 기초를 뗀 개발자, 아바타를 만들어야 하는데 어디서 시작할지 모르는 실무자, 한 학기 교재를 찾는 강사에게 맞습니다. GPU가 없어도 Track B 전체를 완주할 수 있습니다.
```

## 4. AI 사용 여부 및 기여정도

부크크가 경고한 대로, **기여도를 높게 적으면 외부유통이 보류·거절될 수 있습니다.** 사실대로 적되 무엇이 사람의 몫인지 분명히 하세요.

이 책의 실제 상태는 이렇습니다.

- **본문 글** — 저자가 씁니다. 33장 전부 저자의 실험과 수업에서 나온 것이고, 수치는 저자 기계에서 잰 값입니다.
- **코드** — 저자가 씁니다. 공개 저장소에 폴더 34개, 테스트 28개, 실측 결과 40건.
- **이미지** — **일부 생성형 AI**. 표지 아트, 예제 인물(아나운서·면접관·바텐더·마을 사람들), 2D 파츠 예제 그림이 생성 이미지입니다. 도판의 대부분은 저자가 돌린 파이프라인의 산출물 프레임입니다.

→ 선택지 중 **"부분 활용"**(글은 저자, 일부 이미지 생성) 에 해당합니다. "상당수" 로 적을 필요는 없습니다.
