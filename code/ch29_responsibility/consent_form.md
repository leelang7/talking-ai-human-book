# 초상·음성 사용 동의서 — 서식

> Ch29 §3·§4 와 부록 G §1 을 **빈칸이 있는 서식** 으로 옮긴 것입니다.
> Ch28 §6 의 배포 점검(`preflight.py`)이 아래 세 항목 — **어디서 처리되는가 · 보관 기간 · 철회 방법** —
> 이 있는지 확인합니다. 없으면 배포가 막힙니다. 서식에서 지우지 마세요.
> 법률 자문을 대체하지 않습니다.

---

## 1. 누구의 무엇을

| 항목 | 기재 |
|---|---|
| 동의자 (본인) | 성명 · 연락처 |
| 대상 | ☐ 얼굴(사진 ___장 · 영상 ___초) ☐ 음성(___초) ☐ 이름·호칭 |
| 원본 파일 식별자 | 해시 ___________ (생성 로그 `source_assets` 와 같은 값) |
| 미성년·고인·제3자 포함 여부 | ☐ 없음 ☐ 있음 → 법정대리인/유족 동의서 별첨 |

## 2. 무엇을 만드는가 (목적과 범위)

| 항목 | 기재 |
|---|---|
| 만드는 것 | ☐ 말하는 영상 ☐ 실시간 대화 아바타 ☐ 음성 합성 ☐ 기타 ______ |
| 쓰이는 곳 | ☐ 개인 소장 ☐ 교육 ☐ 상업 — 매체·기간: ______ |
| **하지 않는 것** | 동의 범위 밖의 문장을 말하게 하지 않는다 · 다른 맥락에 옮기지 않는다(부록 G §4 맥락 무결성) |

## 3. 어디서 처리되는가 ★

| 항목 | 기재 |
|---|---|
| 처리 위치 | ☐ 제작자의 장비에서만 ☐ 클라우드(___) ☐ **타인의 GPU 로 전송 가능** |
| 민감 입력 | 고인·미성년·의료·법률 맥락이면 ☐ 제작자 장비에서만 (Ch28 §6 — 코드가 강제합니다) |

## 4. 얼마나 보관하는가 ★

| 항목 | 기재 |
|---|---|
| 원본 보관 기간 | ___일 (무기한 불가 — 생성 로그가 0 을 거절합니다) |
| 결과물 보관 기간 | ___일 |
| 기간 뒤 | 원본·결과물·중간 산출물을 삭제하고 로그에 삭제 표시 |

## 5. 어떻게 철회하는가 ★

| 항목 | 기재 |
|---|---|
| 철회 경로 | 연락처 ______ · 처리 기한 ___일 |
| 철회 시 | 원본 해시로 **모든 파생물** 을 찾아 삭제(`genlog.retract`) — 결과물이 어디 있는지 모르면 철회를 이행할 수 없습니다 |
| 이미 배포된 결과물 | 회수 가능 범위와 불가 범위를 명시: ______ |

## 6. 결과물 표시

세 층을 다 씁니다(부록 G §4). ☐ 보이는 표시 ☐ 파일 메타데이터(C2PA 등) ☐ 비가시 워터마크(식별자만)
