# 말하는 AI 휴먼을 만드는 법

> 사진 한 장에서 실시간 대화 아바타까지. 픽셀이 얼굴이 되고, 그 얼굴이 말을 합니다.
> **All That AI · Vol.03** · 이석창 (Seokchang Lee) 지음

도서 *"말하는 AI 휴먼을 만드는 법"* 의 **공식 컴패니언 저장소** 입니다.
책 본문은 포함되어 있지 않습니다 — 여기 있는 것은 **본문의 주장을 실제로 검증하는 코드** 입니다.

---

## 이 저장소가 특이한 점

기술서의 예제 코드는 보통 *본문이 설명한 것을 다시 보여 주는* 역할을 합니다.
이 저장소는 반대 방향으로 만들어졌습니다 — **코드가 먼저 돌고, 그 결과가 본문의 숫자가 됩니다.**

- 본문의 모든 실측값은 `code/chXX_*/_work/` 의 JSON·로그로 거슬러 올라갑니다.
- 감사 스크립트(`scripts/claims_audit.py`)가 **근거 없는 숫자를 본문에서 찾아냅니다.**
- 회귀 테스트 663건이 게이트 하나로 묶여 있습니다.

숫자가 의심스러우면 코드를 돌려 보세요. 다르게 나오면 그것은 오류가 아니라 **자료** 입니다 — [errata.md](errata.md) 로 알려 주세요.

## 빠르게 시작하기

```
git clone https://github.com/leelang7/talking-ai-human-book.git
cd talking-ai-human-book
pip install -r requirements.txt
python scripts/gates.py          # 회귀 테스트 663건 + 스모크 19종
```

종료 코드 0 = 전부 통과. GPU 는 필요 없습니다 — 무거운 모델을 부르는 장은
**실측 결과(`_work/`)를 이미 담고 있어서** 코드만으로 검증됩니다.

GPU 가 필요한 장(Track A · Ch10~15)은 각 폴더의 README 에 환경 구축이 적혀 있습니다.
설치는 **부록 A** 를, 윈도우 특유의 문제는 **부록 H** 를 보세요.

### 여러분의 기계 경로 알려 주기

무거운 모델을 부르는 스크립트는 저장소·환경 경로가 필요합니다. **코드에 박혀 있지 않습니다.**

```
cp book.config.example.json book.config.json     # 열어서 여러분의 경로로 고치세요
```

환경변수가 더 편하면 그쪽이 우선합니다 — `BOOK_MUSETALK`, `BOOK_PY_MUSETALK`, `GEMINI_API_KEY` …
경로를 못 찾으면 스크립트는 **조용히 넘어가지 않고** 무엇을 설정해야 하는지 말하고 멈춥니다.

> **키를 저장소에 두지 마세요.** `.gitignore` 가 `*key*.txt` 를 막고 있지만, 습관이 먼저입니다(Ch28 §2).

## 무엇이 어디에

| 폴더 | 무엇 |
|---|---|
| `code/chXX_*/` | 장별 컴패니언 — 실행 스크립트 · 회귀 테스트 · `_work/`(실측 근거) |
| `code/_lib/` | 장들이 공유하는 최소 유틸(경로 · 미디어) |
| `code/appN_cost/` | 부록 N 원가 계산기 |
| `scripts/` | 원고 검증 도구 15종 — 주장 감사 · 코드 참조 대조 · 조판 검수 |

**33개 장 폴더** 중 27개에 회귀 테스트가, 23개에 실측 근거가 있습니다.

### 트랙별로 고르기

| 트랙 | 만드는 것 | 장 |
|---|---|---|
| **A** | 사진 한 장 → 말하는 영상(mp4) | Ch10~15 |
| **B** | 브라우저에서 도는 실시간 아바타(2D 파츠 · 3D VRM) | Ch16~21 |
| **C** | 그 얼굴에 인격 · 기억 · 지식 | Ch22~27 |

## 검증 도구를 그대로 가져가세요

`scripts/` 는 이 책을 위해 만든 것이지만, **여러분의 기술 문서에도 그대로 쓸 수 있습니다.**

| 스크립트 | 하는 일 |
|---|---|
| `gates.py` | 전부 한 번에. 종료 코드 하나로 |
| `claims_audit.py` | 본문의 숫자를 코드·실측·부록과 대조 — 근거 없는 것을 목록으로 |
| `code_refs.py` | 본문이 이름으로 가리키는 식별자가 코드에 실제로 있는가 |
| `type_qa.py` | 조판 PDF 를 열어 자간 늘어짐 · 상자 여백 · 헐렁한 쪽을 센다 |
| `insight_audit.py` | 장마다 실측 · 실패 · 판단이 몇 문장인가 (일반론 비중) |
